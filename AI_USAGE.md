# AI Usage Disclosure — EquipIntel

## Overview

AI tools were used as development assistants during the creation of EquipIntel for the E9Rental.ai / Equip9 Internet Pvt. Ltd. Connector Challenge 2026.

The tools supported implementation planning, debugging, code development, documentation, and technical problem-solving.

## How AI was used

### 1. Architecture and planning
- Helped break the challenge requirements into development milestones.
- Assisted with designing the Flask application structure.
- Helped plan the database schema and connector architecture.

### 2. Software development
- Assisted in writing and revising Python backend modules.
- Assisted with Flask routes and API integration.
- Helped implement PostgreSQL connectivity and database queries.
- Assisted with Gmail OAuth integration and encrypted token storage.
- Helped develop frontend dashboard components using HTML, CSS, and JavaScript.

### 3. Debugging and testing
- Helped investigate application errors and deployment issues.
- Assisted with SQL query validation and database migration checks.
- Helped troubleshoot Google OAuth and Gmail API integration.
- Assisted with reviewing application behavior locally and on Render.

### 4. Documentation
- Assisted in preparing project documentation, setup instructions, and this disclosure.

## Human involvement

The developer:
- Selected the project direction and implementation priorities.
- Configured the development environment and external services.
- Created and configured the Google Cloud and Supabase projects.
- Tested OAuth connectivity and database operations.
- Reviewed, executed, and iterated on generated code.
- Made implementation and deployment decisions.

AI-generated code was reviewed and tested as part of the development process. AI assistance does not imply that every suggested implementation was accepted or deployed.

## Limitations

AI tools were used as development assistance, not as a substitute for validating integrations.

The current implementation does not include completed WhatsApp or Google Drive connectors. Gmail OAuth and profile retrieval have been tested, while production bulk importing has encountered hosting resource limitations.

The project documentation reflects these limitations rather than claiming unimplemented functionality.

## Transparency

AI assistance was used throughout development. The developer remains responsible for the submitted code, configuration, security, and claims about the application's functionality.
